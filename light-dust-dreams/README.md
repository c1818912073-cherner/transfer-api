# 光尘织梦 · Light Dust Dreams

触摸抚动发光尘粒，顺着柔和风场将它们织入星座。治愈、安静、偏美感反馈——光、粒子、合成音景一体。

## 在微信开发者工具中打开

1. 安装并打开 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 选择 **小游戏** → **导入项目**。
3. **目录** 选本文件夹：`light-dust-dreams`（含 `game.js` / `game.json` / `project.config.json`）。
4. AppID 可用测试号 / `touristappid`。
5. 编译后在模拟器或真机预览；用触摸 / 鼠标拖拽抚尘。

> 离线可玩；无需登录 / 排行榜 / 网络。

## 怎么玩

1. 标题页点 **开始织梦**（首次点击会解锁音频上下文）。
2. **轻抚 / 拖动** 暖金与冷青光尘，拢向星点。
3. 借半透明 **风带** 送尘，或逆风微调。
4. 星点吸满尘粒后 **锁定点亮**，光丝依次相连。
5. 限时内织完 → **星座已成**；超时 → **尘散未聚**，可再开。

关卡：**初织 · 灯笼座**（约 70 秒）。

## 音频（WebAudio 合成音景）

无外部音效资源；`js/audio.js` 用 WebAudio 实时合成一整套声音世界：

| 层 | 说明 |
| --- | --- |
| BGM | 约 8 秒乐句无缝循环：D 调柔和 pad + 固定琶音动机（D–A–E–F#…），偶发风噪铺底；标题 / 局内 / 胜负自动调音量 |
| 抚尘 | 细碎带通噪声 + 微高音粒，按刷动强度节流触发 |
| 入星 | 短促暖铃（双音） |
| 锁定 | 晶莹和弦绽放（分音错开），并短暂压低 BGM（duck） |
| 风声 | 穿越强风区时的柔和 whoosh（冷却，避免刷屏） |
| 通关 | 上行光亮琶音 + 低音垫 |
| 失败 | 下行空气感音列 + 尘散噪声（非刺耳 game-over） |

### 静音 / 试听

- 画布右上角 **「声音 / 静音」** 切换；静音时 master gain 收为 0。
- **微信开发者工具**：真机预览声音最准；模拟器需确认系统与工具未静音。首次触摸后才会 `resume` AudioContext（浏览器自动播放策略同理）。
- **preview.html**：用本地静态服务打开后，点一下画面解锁音频；右上角可静音。
- 微信环境优先 `wx.createWebAudioContext()`，预览页回退到 `AudioContext`。

重要 SFX 触发时会对 BGM 做短暂 duck，避免盖住锁定 / 通关反馈。

## 动效（精致向）

刻意编写的运动时刻（非模板 tween 堆砌）：

1. **标题 idle** — 标题呼吸缩放 + 环绕微尘 + 按钮轻吸
2. **抚尘丝带** — 速度对齐的光尘拖尾与星屑
3. **入星脉冲环** — 尘粒落入时的柔和扩散环
4. **星座成型** — 锁定过冲绽放、光丝错峰描出、线上游走光点
5. **风带涟漪** — 弯曲微光丝带 + 沿线闪烁
6. **胜 / 负转场** — 通关暖光 bloom 与文字上浮；失败暗角 vignette、尘粒四散

缓动以 `js/ease.js` 的 cubic / backOut / damp 为主，避免生硬弹出。

## 美术方向

- 深夜柔和天空：`#070e1a` → `#1a2a3a`（避开紫霓虹套路）
- 光尘：暖琥珀金 + 冷水青
- 反馈以辉光、丝带、锁定绽放、空气感音色为主
