# 光尘织梦 · Light Dust Dreams

触摸抚动发光尘粒，顺着柔和风场将它们织入星座。治愈、安静、偏美感反馈——几乎全靠光与粒子。

## 在微信开发者工具中打开

1. 安装并打开 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 选择 **小游戏** → **导入项目**（或「+」新建后选导入）。
3. **目录** 选本文件夹：`light-dust-dreams`（包含 `game.js` / `game.json` / `project.config.json` 的目录）。
4. AppID 可用测试号 / `touristappid`（已写在 `project.config.json`）。
5. 编译后在模拟器或真机预览中游玩；**请用触摸 / 鼠标拖拽** 抚尘。

> 本原型不依赖登录、排行榜或网络；离线即可玩完一整局。

## 怎么玩

1. 标题页点 **开始织梦**。
2. **手指轻抚 / 拖动**：把暖金与冷青光尘轻轻拢向星点。
3. 留意半透明 **风带**——尘粒会被气流轻轻带偏，可借力也可逆风。
4. 每个星点需要足够多的尘粒靠近才会 **点亮锁定**；连线会随之亮起。
5. 在倒计时内点亮全部星点即 **星座已成**；超时则 **尘散未聚**，可再开一局。

本原型关卡：**初织 · 灯笼座**（约 70 秒）。

## 项目结构

```
light-dust-dreams/
├── game.js                 # 入口
├── game.json               # 小游戏配置（竖屏）
├── project.config.json     # 开发者工具工程配置
├── js/
│   ├── art.js              # 色彩与美术方向
│   ├── input.js            # 触摸 / 拖拽
│   ├── particles.js        # 光尘 + 拖尾
│   ├── wind.js             # 风场 + 微光闪烁
│   ├── levels.js           # 星座目标与时限
│   ├── ui.js               # 标题 / HUD / 胜负
│   └── main.js             # 主循环与场景切换
└── preview.html            # 可选：浏览器预览（非正式运行环境）
```

## 美术方向（简述）

- 深夜柔和天空：`#070e1a` → `#1a2a3a`，无紫霓虹套路。
- 光尘：暖琥珀金 + 冷水青；反馈以辉光、拖尾、锁定绽放为主。
